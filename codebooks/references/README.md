# External Reference Terminologies

This directory contains externally developed reference terminology resources used in the project. These resources are not original codebooks developed by the study author.

## Cumulus Opioid Value Set

**File:** `cumulus_opioid_valueset.tsv`

**Source:** SMART Health IT / Cumulus Opioid Value Set Supplement

**Publication:** Wasz et al. (2026). *Development and validation of a near-comprehensive RxNorm valueset of opioid medications*. *JAMIA Open*.

**Source repository:** https://github.com/smart-on-fhir/cumulus-library-opioid-valueset-supplement

**License:** Apache License 2.0 (as stated in the source repository; retain the applicable license and attribution information).

**Version:** GitHub commit SHA to be recorded.

**Retrieval date:** To be recorded.

**File integrity:** SHA-256 checksum to be recorded.

### Purpose

This externally developed RxNorm-based value set is used as the primary reference for identifying opioid-related medication concepts in MIMIC-IV-ED Pyxis records.

The original reference file is preserved without modifications. Project-specific medication matching, auditing, and outcome construction are performed separately.

### Attribution

The Cumulus Opioid Value Set was developed by its original authors. Its inclusion in this repository does not imply that the value set was created, clinically validated, or maintained by the author of this project.

The original publication and source repository should be cited when describing the medication classification methodology.
